Endpoint reference

POST/cloud/v1/createSession
Provisions an account and requests the game. Streams NDJSON lifecycle events.
// body: { "game_key": "fortnite" }   header: x-api-key: sk_live_…
{"status":"creating_account"}
{"status":"account_ready"}
{"status":"requesting_game"}
{"status":"queue","uuid":"…","queue_pos":4}
{"status":"finished_queue","uuid":"…","fetch_this_within_30s_or_terminate":"/cloud/v1/startGame"}
GET/cloud/v1/getQueue?uuid=…
Polls queue position (min every 3s). Call within 60s or the session is abandoned.
{"status":"queue","queue_pos":2}
// → {"status":"finished_queue","uuid":"…","fetch_this_within_30s_or_terminate":"/cloud/v1/startGame"}
POST/cloud/v1/startGame
Activates the session; returns WebRTC ICE servers and the signaling socket. Call within 30s of finished_queue.
// body: { "uuid": "…" }
{
  "ice_servers": [{ "urls": "stun:stun.l.google.com:19302" }],
  "signaling_ws": "wss://api.stratus.lol/cloud/v1/signal/",
  "max_seconds": 900
}
WS/cloud/v1/signal/{uuid}
WebRTC signaling proxy. Await game_ready, send an SDP offer, apply the answer, trade ICE candidates.
server → { "type": "game_ready" }
client → { "type": "rtc_offer", "sdp": "…" }
server → { "type": "rtc_answer", "sdp": "…" }
both   ↔ { "type": "rtc_candidate", "candidate": {…} }
POST/cloud/v1/pingSession
Keepalive every ~30s. Returns session time used and per-window quota.
// body: { "uuid": "…" }
{
  "session_time_used_seconds": 42,
  "session_time_limit_seconds": 900,
  "quota": { "minute": {"used":3,"limit":30}, "hour": {"used":12,"limit":300}, … }
}
POST/cloud/v1/quitSession
Terminates the session and releases cloud resources.
// body: { "uuid": "…" }  →  {"status":"ok"}
